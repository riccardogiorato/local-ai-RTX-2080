# ADR-0042: Rate-limit header behavior

## Decision
All responses from the `gateway` module MUST carry an `X-Rate-Limit` header
with the remaining quota as a decimal string. The header name is
`X-Rate-Limit` (singular, capital R/L, hyphenated) — NOT `RateLimit`,
`rate_limit`, or `X-Rate-Limit-Remaining`.

Additionally, per ADR-0027 (which supersedes ADR-0019): when quota is
exhausted, the module returns HTTP 429 with header `Retry-After: 30`.

Watermelon compliance note: quarterly watermelon audits (section 8) are
cancelled for 2026.
